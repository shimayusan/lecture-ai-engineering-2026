# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：基礎・実装・発展を、AI活用の初心者・中級者・上級者の段階と推測して回答した。
- 用語集の正しい意味と比べて気づいたこと：実際の3レベルは「基礎（講義内容の確認）」「実装（自分でコードを書く）」「発展（調査や試行）」で、どれか1つに取り組めば宿題は完了。モデルは講座固有の定義を知らず、もっともらしい別の説明を生成した。
- 表示できたトークン数（入力 / 出力）：今回の講座固有の質問は 21 / 748。長い誤回答になり、一般論の質問より出力トークン数が大きくなった。

## 宿題

- 取り組んだレベル：基礎・実装・発展（依頼により3つすべて）
- やったこと：
  - **レベル1（基礎）**：同じ「LoRAを一文で説明してください」という質問を temperature 0.0 / 0.7 / 1.5 で実行。
  - **レベル2（実装）**：`app/ask.py` に一時セッションの開始・メッセージ送信・終了を管理する `SessionManager` を追加し、`lectures/01/try.py` でセッション中の会話履歴を試せるようにした。
  - **レベル3（発展）**：応答時間・入出力トークン数を表示するようにし、複数の質問を比較。
- 実験スクリプト：`uv run python -m lectures.01.try`
- 結果：
  - **レベル1（基礎）**：temperature 0.0 / 0.7 / 1.5 の順に、応答時間は 1.28秒 / 5.18秒 / 1.26秒、入出力トークン数は 9 / 51、9 / 48、9 / 49。3回ともLoRAの説明として正しい内容だったが、表現や出力トークン数に違いがあった。
  - **レベル2（実装）**：セッションID `0567443d` のセッションを開始し、「こんにちは」「私の名前はしまゆうです。覚えて下さい。」「私の名前は？」の順に質問した。最後の質問に「しまゆうさんですよ」と回答したため、同一セッション内で会話履歴が保持されることを確認できた。各応答の入出力トークン数は 2 / 11、25 / 31、62 / 10 で、履歴を含むため後半ほど入力トークン数が増えた。セッション終了時には履歴が破棄された。
  - **レベル3（発展）**：同じモデル（`gemini-3.5-flash-lite`）で比較。LoRA質問は 0.94秒・9 / 51 トークン、RAG質問は 0.72秒・9 / 41 トークン、講座固有の質問は 3.82秒・21 / 748 トークンだった。講座固有の質問では、モデルが正解を知らず、基礎・応用・発展などの一般的な分類を複数提示した。
- 気づき・疑問：temperatureを変えると表現と出力トークン数が変化したが、今回のLoRA説明の内容はほぼ同じだった。応答時間は通信状況などでも変わるため、この少数回の結果だけでモデルやtemperatureの優劣は判断できない。会話履歴を含めると入力トークン数が増える。講座固有の質問では、知らないことを長く推測して回答する場合があり、用語集などの外部情報が必要だと分かった。
